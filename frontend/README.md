# Frontend README

This is the frontend for AI Interviewer, a modern mock interview platform built with React and Vite.

Created by Nandini Mittal.

Live demo: https://mockinterviewerai.netlify.app/

## Available Scripts

- npm run dev - start the Vite development server
- npm run build - create a production build
- npm run preview - preview the production build locally
- npm run lint - run ESLint checks

## Features

- Landing page with interview preparation content
- Authentication screens for login and signup
- Protected dashboard and interview experience
- Responsive UI for mobile and desktop

## Setup

```bash
npm install
npm run dev
```

## Notes

- The frontend expects the backend API to be running.
- Configure the API base URL in the frontend environment/config files if needed.
